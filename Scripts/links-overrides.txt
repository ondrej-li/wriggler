# Hand-traced links for the Wriggler maze.
#
# These win over the automatic trace in extract_links.py. Each line joins two
# exits; the reverse direction is filled in automatically, so a pair only needs
# writing once. Trailing comments are ignored.
#
# Notation: row,col,slot with 0,0 at the top-left of the map.
#   0 1 2   top, left to right      6 7 8   bottom, right to left
#   3 4 5   right, top to bottom    9 a b   left, bottom to top
#
# A line starting with "-" drops an exit the trace produced but which does not
# correspond to a real exit.
#
# Sorted by the first exit, for easy scanning.
